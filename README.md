# 🤖 Robot Control — Управление роботом-манипулятором

Приложение для управления 6-DOF роботом-манипулятором **Rooky Arm** в реальном времени.
Поддерживает работу с реальным роботом (через COM-порт) и симуляцию в **MuJoCo**.
Интегрирована система обратной связи от 7 датчиков угла поворота **AS5600**
через мультиплексор **TCA9548A**.

## ✨ Возможности

### Управление роботом
- **Ручное управление** — покнопочное перемещение каждого из 6 суставов (MoveJ / MoveL)
- **Управление схватом** — открытие / закрытие + плавный слайдер
- **Домашняя позиция** — возврат во все нули одной кнопкой
- **Экстренная остановка** — мгновенная остановка всех приводов
- **Пауза / Продолжение** — приостановка симуляции

### Симуляция MuJoCo
- **3D-визуализация** робота в реальном времени (обзорная камера)
- **Виртуальная камера** — имитация рабочей камеры над столом
- Физически корректная модель с гравитацией, инерцией, столкновениями
- Объекты на сцене (кубы, цилиндры, сферы) для тестирования захвата

### Датчики AS5600 × 7
- Одновременное чтение 7 датчиков угла поворота через **TCA9548A**
- Маппинг каналов Arduino → суставы робота (настраивается в конфиге)
- Калибровка: масштаб, инверсия, смещение нуля для каждого канала
- Сглаживание показаний (EMA-фильтр)
- Индикация состояния магнита (OK / WEAK / STRONG / NONE)

### Камера + Детекция
- Захват с реальной USB-камеры или виртуальной (MuJoCo)
- Детекция цветных объектов по HSV-диапазонам
- 4 цвета из коробки: красный, зелёный, синий, жёлтый
- Контуры, bounding boxes, подсчёт объектов

### Конфигурация
- Единый файл `config.yaml` (или `config.json`)
- Горячая перезагрузка конфигурации
- Значения по умолчанию для всех параметров

## 🎯 Быстрый старт

### Запуск симуляции (без оборудования)

```bash
python robot_control.py
```

1. Режим → **🖥 Симуляция (MuJoCo)**
2. Путь к модели уже заполнен из конфига (`models/rooky_arm.xml`)
3. Нажать **🔌 Подключить**
4. Появится 3D-вид робота на столе
5. Вкладка **🎮 Управление** → кнопки **+/−** для каждого сустава

### Запуск с реальным роботом

```bash
python robot_control.py
```

1. Режим → **🤖 Реальный робот (MCX)**
2. Указать COM-порт (напр. `COM39`)
3. **🔌 Подключить**

### Запуск с датчиками AS5600

1. Загрузить скетч `arduino/tca9548a_7x_as5600.ino` в Arduino
2. В программе: вкладка **🔄 Датчики AS5600**
3. Выбрать порт Arduino, нажать **▶**
4. Включить **☑ Управление ВКЛ**
5. Вращать валы датчиков → робот двигается

## ⚙ Конфигурация

Приложение ищет файлы в порядке приоритета:
1. `config.yaml` (рекомендуется)
2. `config.yml`
3. `config.json`

Если файл не найден — используются значения по умолчанию из `config.py`.

### Основные секции

| Секция | Описание |
|--------|----------|
| `application` | Размер и заголовок окна, интервал обновления |
| `robot` | Режим по умолчанию, COM-порт, путь к XML |
| `mujoco` | Размеры рендера, имена камер, шаг симуляции |
| `joints` | 6 суставов: имена, лимиты, маппинг на MuJoCo, инверсия GUI |
| `gripper` | Параметры схвата: актуатор, диапазон, инверсия |
| `sensor` | COM-порт Arduino, 7 каналов: маппинг, калибровка |
| `detection` | HSV-диапазоны цветов, параметры морфологии |
| `camera` | Индекс камеры, виртуальная камера |
| `gui` | Шрифты, подписи осей |
| `logging` | Путь к файлу логов |

### Пример: сменить маппинг датчиков

```yaml
sensor:
  channels:
    - channel: 0
      target: "joint"
      joint_index: 2      # CH0 → J3 (вместо J1)
      invert: true         # Инвертировать направление
      scale: 0.5           # Половинный масштаб
```

### Пример: инвертировать направление сустава в GUI

```yaml
joints:
  - name: "J2"
    gui_invert: true       # + кнопка = рука ОТ стола
```

### Программный доступ

```python
from config import cfg

# Чтение
fps = cfg.get("mujoco.rendering.fps", 25)
port = cfg.get("sensor.port", "COM3")

# Запись
cfg.set("sensor.port", "COM5")
cfg.save()

# Перезагрузка
cfg.reload()
```

## 🦾 Модель MuJoCo

Файл: `models/rooky_arm.xml`

### Кинематическая цепь

```
Стол (z = 0.92 м)
 └─ base_mount (красный бокс)
     └─ J1: Base Pitch      (ось Y)  ± 80°
         └─ J2: Shoulder Pitch (ось X)  ± 41.5°
             └─ J3: Shoulder Roll  (ось Z)  ± 86.5°
                 └─ J4: Elbow Pitch    (ось X)  ± 40°
                     └─ J5: Forearm Roll   (ось Z)  ± 86°
                         └─ J6: Wrist Pitch    (ось X)  ± 25.75°
                             └─ Схват (J5_grip)  ± 74.5°
                                 ├─ Большой палец (фикс.)
                                 └─ 4 пальца (подвижные)
```

### Элементы модели

| Элемент | Описание |
|---------|----------|
| Пол | Плоскость 6×6 м |
| Стол | Столешница + 4 ножки, высота 0.92 м |
| Красный бокс | Основание робота на столе |
| Красный куб | Свободный объект для захвата |
| Зелёный цилиндр | Свободный объект |
| Синяя сфера | Свободный объект |
| Жёлтый кубик | Свободный объект |
| overview_cam | Обзорная камера (вид сбоку-сверху) |
| work_cam | Рабочая камера (вид сверху) |
| tcp | Сайт TCP на ладони схвата |

### Сенсоры

| Имя | Тип | Назначение |
|-----|-----|------------|
| `sens_pos_1`…`6` | jointpos | Положения суставов |
| `sens_vel_1`…`6` | jointvel | Скорости суставов |
| `sens_frc_1`…`6` | actuatorfrc | Усилия актуаторов |
| `tcp_pos` | framepos | Позиция TCP (x, y, z) |
| `tcp_quat` | framequat | Ориентация TCP (кватернион) |

## 🔄 Датчики AS5600

### Аппаратная часть

```
Arduino Uno/Nano
  │ I2C (SDA, SCL)
  │
  ▼
TCA9548A (0x70)
  ├─ CH0 → AS5600 → Сустав J1
  ├─ CH1 → AS5600 → Сустав J2
  ├─ CH2 → AS5600 → Сустав J3
  ├─ CH3 → AS5600 → Сустав J4
  ├─ CH4 → AS5600 → Сустав J5
  ├─ CH5 → AS5600 → Сустав J6
  └─ CH6 → AS5600 → Схват
```

### Протокол (Serial, 115200 бод)

```
# Данные (20 Гц на каждый канал):
AS5600:0,45.23,1845,128,2048,OK
AS5600:1,12.80,524,130,2100,OK
...
AS5600:6,50.50,566,127,2048,OK

# Ошибки:
AS5600:3,ERR_MUX       # Мультиплексор не отвечает
AS5600:5,ERR_NODEV     # Датчик отключён

# Комментарии (логируются):
# TCA9548A + 7x AS5600 System Ready

# Команды (от PC → Arduino):
PING                    # → PONG
SCAN                    # Пересканировать датчики
STATUS                  # Маска подключённых
```

### Калибровка

Для каждого канала в `config.yaml`:

| Параметр | По умолчанию | Описание |
|----------|:------------:|----------|
| `scale` | 1.0 | Масштаб (1° датчика → N° сустава) |
| `offset_deg` | 0.0 | Начальное смещение нуля |
| `invert` | false | Инверсия направления |
| `smoothing` | 0.30 | EMA-фильтр (0.01 = плавно, 0.99 = резко) |

## 🎮 Управление

### Клавиши GUI

| Элемент | Действие |
|---------|----------|
| **+/−** кнопки | Шаг сустава на N° (настраивается) |
| **Шаг** спинбокс | 1–45° за клик |
| **MoveJ / MoveL** | Режим: по суставам / линейно |

| **Слайдер** | Плавное управление схватом |
| **🏠 HOME** | Все суставы → 0° |
| **⛔ СТОП** | Экстренная остановка |
| **ПАУЗА / ПРОДОЛЖИТЬ** | Приостановка симуляции |

| Вкладка | Содержимое |
|---------|------------|
| **🎮 Управление** | MoveJ/L, кнопки осей, схват |
| **🔄 Датчики** | 7 каналов AS5600, калибровка, маппинг |

| Вкладка | Содержимое |

## 🔧 Устранение неполадок

### MuJoCo не запускается

```
[MuJoCo] Библиотека не найдена — pip install mujoco
```

**Решение:**
```bash
pip install mujoco
```

### Модель не найдена

```
[MuJoCo] XML-модель не найдена: models/rooky_arm.xml
```

**Решение:** убедитесь, что файл `models/rooky_arm.xml` существует
относительно рабочей директории.

### Робот не поворачивается на полный диапазон

**Причины:**
- Маленький шаг (увеличьте в спинбоксе)
- Низкий `kp` в модели → рука не может преодолеть гравитацию

**Решение:** в `models/rooky_arm.xml` увеличить `kp` актуаторов
(200–300 для основных суставов).

### Суставы двигаются в обратную сторону

**Решение:** в `config.yaml` для нужного сустава:

```yaml
joints:
  - name: "J2"
    gui_invert: true
```

### Датчики AS5600 не подключаются

```
[Sensors] Ошибка порта: could not open port 'COM3'
```

**Проверьте:**
- Arduino подключена и порт не занят другой программой
- Правильный COM-порт в списке
- Драйвер CH340/CP2102 установлен
- Порт датчиков ≠ порт робота

### Камера не открывается

```
[Камера] Не удалось открыть #0
```

**Решение:** попробуйте другой индекс (1, 2, …)
или включите виртуальную камеру MuJoCo.

### Конфиг не загружается

```
[Config] ⚠ pyyaml не установлен
```

**Решение:**
```bash
pip install pyyaml
```

Или используйте `config.json` вместо YAML.
